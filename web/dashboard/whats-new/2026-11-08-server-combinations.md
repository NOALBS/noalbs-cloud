Streaming through more than one server at once? NOALBS can now use different scenes while certain servers are live
together. Say your BELABOX and a backpack cam both stream: show a two-camera layout while both are up, and go back to
your normal scenes as soon as one drops.

To set one up, open a switcher, go to **Scenes** and tap **Add combination** under **Server combinations**. Pick two
or more servers, then the LIVE, LOW and BRB scenes to use while all of them are live.

- **All of its servers live:** a combination is used while every server in it has a feed, even if other servers are
  live too.
- **The highest one wins:** when more than one combination fits, the one highest in the list is used. Drag them to
  change the order. If one can never be used because a combination above it always matches first, it says so.
- **LIVE or LOW** still follows your top server, like before. Leave a scene on **Server's scene** to keep what that
  server would show.
- **BRB:** when every server drops, the BRB scene of the combination last in use is shown.
- **No flip-flopping:** switching onto or off a combination waits as many checks as a LIVE to LOW switch
  (**Checks before switching**), so an uplink that keeps dropping in and out doesn't flip your layout back and forth.

The combination on air shows **in use**. Each has a switch to turn it off without deleting it, and removing a server
also removes the combinations it's in.
