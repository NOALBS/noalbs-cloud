# Security

NOALBS Cloud holds things streamers care about: control over their OBS, stream server keys, BELABOX and
Moblin access and chat bot grants. If you find a way to get at any of that, please tell us privately.

## Reporting

- Use [GitHub's private vulnerability reporting](https://github.com/NOALBS/noalbs-cloud/security/advisories/new), or
- email **support@noalbs.com** with "Security" in the subject.

Please don't open a public issue or post it on Discord. Say what you found, how to reproduce it and what
someone could do with it. We'll answer within a few days, keep you posted while we fix it and credit you
when it's out, unless you'd rather not be named.

## Testing against the hosted service

Use your own accounts and workspaces only. Don't access other people's data beyond what's needed to
show the problem, don't run denial-of-service or load tests, and don't spam chat channels through the
bot. Better still, run your own copy (see the [README](README.md)): it has fakes for every platform and device.

## Supported versions

Only the current `main` branch, which is what the hosted NOALBS Cloud runs.
