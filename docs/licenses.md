# Licenses

NOALBS Cloud itself is licensed under the GNU Affero General Public License v3.0 or later (`LICENSE`,
`AGPL-3.0-or-later` in every `Cargo.toml` and `package.json`). Its section 13 means anyone who runs a
modified copy as a service must offer its users the source: `/licenses` links the repository for that,
so a fork that's hosted changes that link to its own. The BELABOX remote control is written from
belaUI's GPL-3.0 source, which is one reason the project can't be under a permissive license.

`/licenses` (`web/dashboard/licenses.html`) links two text files with the licenses of the open source
we ship. MIT, ISC, BSD and Apache-2.0 ask that the copyright and license text travels with the code,
and the dashboard's JavaScript is sent to every visitor's browser, so this isn't optional.

| File | Covers | How it's made | Committed? |
| --- | --- | --- | --- |
| `/third-party-licenses.txt` | Production npm packages of the dashboard and browser source, with full license texts | `web/dashboard/scripts/js-licenses.mjs` (uses `pnpm licenses list --prod`) | No, generated on every `pnpm build` |
| `/rust-licenses.txt` | Rust crates linked into `api`, `obs-link` and `chat`, with the license each declares | `web/dashboard/scripts/rust-licenses.mjs` (uses `cargo metadata`) | **Yes** |
| `/third-party-notices.txt` | Software we implement protocols of (BELABOX/belaUI, Moblin): copyright and license texts | By hand | **Yes** |

## When to do something

**Rust dependencies changed (`Cargo.lock`):** regenerate and commit the list. From the repo root:

    node web/dashboard/scripts/rust-licenses.mjs

It must be committed because the dashboard image is built from `web/dashboard` alone, without the Rust
workspace. The script only lists normal dependencies (not dev or build ones). Read its warnings:

- `no license field`: look the crate up and check its license by hand.
- `check: <crate> is <license>`: a license that can't be combined with our own AGPL-3.0 (GPL-2.0-only,
  SSPL, CDDL, EPL). Don't ship it; find another crate. GPL-3.0, AGPL-3.0, LGPL and the permissive
  licenses are all fine.

**npm dependencies changed:** nothing to do. The JS file is regenerated by `pnpm build`
(and by hand with `pnpm gen:licenses`, which writes `public/third-party-licenses.txt` for `pnpm dev`).
Check the new package's license is permissive: `pnpm licenses list --prod`.

**New thing shipped to browsers that isn't an npm package** (a vendored script, a font file, an image
or icon set): add its license to `licenses.html` by hand.

**Code ported from another project** (NOALBS v2's stream servers, belabot, Moblin's protocol, ...): keep
the original copyright notice if its license requires it, and mention it on `licenses.html` (BELABOX/belaUI, GPL-3.0, and Moblin, MIT: credit lines on
the page, texts in the committed `public/third-party-notices.txt`).

## Checking

    cd web/dashboard && pnpm build

then open `dist/third-party-licenses.txt`, or run `pnpm dev` and visit `/licenses`.
`/licenses` is a reserved workspace slug and in `NOT_THE_APP` (`src/lib/redirect.ts`), like `/privacy`
and `/terms`.
